```java
import java.util.*;

public class NetworkDeployment {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int m = scanner.nextInt();
        int k = scanner.nextInt();
        
        // 构建流量矩阵
        int[][] flow = new int[n][n];
        int totalFlow = 0;
        for (int i = 0; i < k; i++) {
            int a = scanner.nextInt() - 1; // 转为0-indexed
            int b = scanner.nextInt() - 1;
            int f = scanner.nextInt();
            flow[a][b] = f;
            flow[b][a] = f;
            totalFlow += f;
        }
        
        int size = 1 << n; // 状态总数：2^n
        
        // 预计算：每个子集的内部流量
        int[] internal = new int[size];
        for (int mask = 0; mask < size; mask++) {
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) {
                    for (int j = i + 1; j < n; j++) {
                        if ((mask & (1 << j)) != 0) {
                            internal[mask] += flow[i][j];
                        }
                    }
                }
            }
        }
        
        // DP数组：dp[mask]表示状态mask下的最大组内流量
        int[] dp = new int[size];
        Arrays.fill(dp, -1);
        dp[0] = 0; // 初始状态：没有服务器
        
        // 状态转移
        for (int mask = 0; mask < size; mask++) {
            if (dp[mask] == -1) continue;
            
            int remaining = ((1 << n) - 1) & ~mask; // 未分配的服务器
            
            // 枚举所有可能的子集（大小不超过m）
            for (int subset = remaining; subset != 0; subset = (subset - 1) & remaining) {
                if (Integer.bitCount(subset) <= m) {
                    int newMask = mask | subset;
                    int newValue = dp[mask] + internal[subset];
                    if (newValue > dp[newMask]) {
                        dp[newMask] = newValue;
                    }
                }
            }
        }
        
        // 结果计算：总流量 - 最大组内流量
        int result = totalFlow - dp[size - 1];
        System.out.println(result);
    }
}
```

### 思路
1. **1.**

**<font style="color:rgb(0, 0, 0);">问题转化</font>**<font style="color:rgb(0, 0, 0);">：將服务器分组，每组大小不超过m，最大化组内服务器之间的流量和（因为组内流量不贡献三层流量）。最小三层流量 = 总流量 - 最大组内流量和。</font>

2. **2.**

**<font style="color:rgb(0, 0, 0);">动态规划（DP）</font>**<font style="color:rgb(0, 0, 0);">：使用状态压缩DP，状态用位掩码表示已分组的服务器集合。对于每个状态，枚举剩余服务器的所有非空子集（大小不超过m）作为新组，更新DP状态。</font>

3. **3.**

**<font style="color:rgb(0, 0, 0);">预计算</font>**<font style="color:rgb(0, 0, 0);">：预计算所有服务器子集的内部流量和，以便在DP中快速查询。</font>

4. **4.**

**<font style="color:rgb(0, 0, 0);">复杂度</font>**<font style="color:rgb(0, 0, 0);">：由于n和m最多15，状态数为2^n = 32768，枚举子集的总复杂度约为3^n = 14348907，在Java中可行。</font>
